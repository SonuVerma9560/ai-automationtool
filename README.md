# AI Business Automation Tool 🚀

This project is an AI-powered business automation system that analyzes CSV/TXT data, generates insights, and automates reporting.

## 🔥 Features
- Upload CSV / TXT files
- Generate business insights using LLM
- Auto-generate email reports
- Send email via SMTP
- Download report

## 🧠 Tech Stack
- Python
- Streamlit
- Pandas
- Groq API (LLaMA 3.1)
- SMTP (Email Automation)
